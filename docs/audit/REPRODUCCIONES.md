# Reproducciones y límites de la auditoría

Todas las pruebas con escritura utilizaron Miniflare/D1 aislado y datos ficticios. No se ejecutaron ataques, escrituras, borrados ni migraciones en la base publicada.

- **Dominio SEO anterior:** en el commit v21, `lib/magia-data.ts` exportaba `magia-archive.mcservereden.chatgpt.site`; `generateMetadata` lo usaba en canonical y en los nueve hreflang. Corregido al dominio confirmado por Sites.
- **Prueba de Google incompleta:** `node --test tests/google-worker.test.mjs` devuelve 503 en favoritos al disponer solamente de la migración 0000. Cambiar la preparación de prueba para aplicar las cuatro migraciones devuelve 200. El código de autenticación no cambió.
- **Selector móvil estrecho:** `app/expansion.css`, media query hasta 650 px, fijaba 85 px de ancho máximo, mientras el contenido visible usaba el nombre completo del idioma, con icono y padding. Preparados nombres compactos con nombre accesible completo, menú con nombres enteros y cabecera en dos filas hasta 400 px. Falta inspección visual real a 320/360/375/390/430/768/1440 px.
- **Combobox incompleto:** Madokadle añadía `role="combobox"` a un botón que abre un Popover de tipo diálogo, sin todas las propiedades de combobox. Preparada semántica de botón con `aria-haspopup="dialog"`, `aria-expanded` y enlace al contenido.
- **Dependencia RSC afectada en v21/v22:** `node_modules/react-server-dom-webpack/package.json` y lockfile acreditaban 19.2.6; GHSA-wx67-qw84-cm4g incluye esa versión. Vinext usa el sistema RSC. No se ha demostrado explotación ni se ha enviado el payload del aviso al Site. Tras autorización del usuario se actualizó el borrador a 19.2.8, junto con React/React DOM y Vite 8.1.6; ver `ACTUALIZACION_SEGURIDAD.md`. Producción sigue sin actualizarse.
- **Carga inicial:** la compilación original incluye `magia-portal` de 1.364.867 bytes (402.705 bytes gzip calculado localmente). No son bytes transferidos medidos en una sesión móvil.
- **DOM pesado:** SSR del catálogo de retratos genera 8.063 elementos y su tier list 10.739; los rangos cerrados todavía tienen hijos en el HTML. No es una medida de INP ni del coste de pintura del navegador.
- **JSON público corrupto:** llamar `mergeKiokus([{key:'kioku:10010701',value_json:'{'}])` lanza SyntaxError. `readPublicContent` tiene un catch global y retorna todo el contenido inicial. Se reproduce localmente el riesgo de degradar datos dinámicos de toda la página ante un solo registro corrupto; no se encontró un registro corrupto en producción.
- **Semántica de publicación:** un artículo con esquema válido puede indicar categoría anime y región global conservando una URL japonesa de Exedra. La comprobación de servidor valida origen/estructura y que la página tenga body, pero no prueba que la traducción, región o fecha coincidan con el anuncio. La revisión semántica depende del plan del agente editor.
- **Fechas:** la prueba con `2026-02-30` fue rechazada por el esquema; no se clasifica como un defecto confirmado. No se publicó ninguna fecha de prueba.
- **Concurrencia editorial:** las escrituras de catálogos usan hora de finalización, no una comparación atómica de revisión de la wiki; `saveArticle` no condiciona el UPDATE a la fecha de comprobación. Una ejecución antigua que termine después puede sobrescribir datos más recientes. Es una ruta de riesgo deducida del código; no se indujo una carrera en producción ni se modificó el importador.

Los errores de las consultas web se registraron como bloqueos de acceso, no como defectos de la aplicación. Los JSON recortados por la vista de tablas se trataron como información incompleta, no como evidencia de corrupción de datos. Una variable secreta devuelta como null se trató como valor oculto, no como variable vacía.
